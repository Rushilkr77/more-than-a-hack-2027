# P4: bidirectional GRU

P4 reads each half as a sequence. A bidirectional GRU (Cho et al. 2014) over the common flat per-frame inputs gives
P(H), P(A), P(D) for every frame, and the common Viterbi smoother decodes them. Where P2 sees time only through
hand-built 1/5/15 s summaries, the GRU learns its own context from the raw schema columns, looking both back and ahead
(`OFFLINE_ACAUSAL`, IL-011).

It uses only the common layer (`src/common/sportec.py`): same split, labels, mirrored copies, penalty grid, smoother,
scorer and `keep_rule`. Every choice below was made on Sportec validation with `keep_rule`; public BAR-ATH is reported
but never used to choose (RULES.md rule 2). The Sportec test match J03WQQ was scored once, after freezing.

## Final P4

`04_g0_w30_s5_aug2_ens`: schema `04_full_phase_context` without `gtag_*` (72 columns + 51 observed flags), 30 s windows,
every 5th frame, 2 extra damaged copies of each training match, hidden 64 x 2 layers, 3-seed probability ensemble,
common smoother at penalty 20.

```bash
python scripts/build_p4_aug.py --copies 2               # P4-local damaged training copies, cache/p4/ (once)
python scripts/train_p4.py --seed 0 --seed 1 --seed 2   # three seed runs
python scripts/train_p4.py --ensemble --bar-ath         # average their probabilities, tune penalty, smooth once
```

Needs `torch==2.14.1` (CPU). Training is deterministic for a given seed (`torch.use_deterministic_algorithms`), so the
same commands regenerate the same files (rule 3).

## Pieces around the GRU

- **Missing values (GRU-D-lite, IL-009):** standardise with training statistics, NaN to 0, plus a 0/1 observed column
  for every feature that can be missing.
- **Windows:** 30 s, never across halftime; hidden state starts fresh in each window. Inference uses 50% overlap and
  keeps each frame's prediction from the window whose centre is nearest (edges have one-sided context).
- **Frame rate:** trained on every 5th frame; at inference each of the 5 phase offsets runs as its own sequence, so
  every frame gets its own prediction.
- **Training:** AdamW 1e-3, cross-entropy on raw labels, gradient clip 1.0, dropout 0.3, early stop on validation
  cross-entropy (patience 5, best epoch about 9-13).
- **Damaged copies (A2, `scripts/build_p4_aug.py`):** the common damage code and ranges
  (`scripts/build_sportec_bundles.py`) rerun on the 4 training matches with new fixed seeds (match seed + 100 k).
  Copy 1 hides the ball about 42% of the time with long gaps (median 12 s), copy 2 about 50% with short gaps (7 s).
  Gaps are placed without looking at labels, and nothing is fitted to BAR-ATH. Validation and test are never copied.
  The two copies together beat either alone; four copies add nothing. The gain shows most where the ball is missing:
  live-play accuracy on missing-ball frames 0.81 -> 0.84, dead-ball precision 0.91 -> 0.93.

Not used: a CRF/HMM layer (the common smoother does that job), attention, class weights (dead ball is about 44% of
frames), full GRU-D decay, temperature scaling.
