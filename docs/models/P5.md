# P5: local-global Transformer — completed negative result

Date: 2026-11-16

## Decision

P5 is complete as a reproducible negative experiment. Do **not** replace P4 or
the stronger blend recorded in PR 16.

The three-seed local-convolution + Transformer ensemble reached 0.675
validation spellF1, versus P4's recorded 0.710. One pre-declared 50/50 blend
with P2 improved P5 to 0.695, but remained below P4 and failed the common keep
rule against the simpler P2 baseline. Open PR 16 now records 0.727 for its
P2/GRU blend, widening the gap. No P5 blend-weight search or architecture
growth was performed after seeing validation results.

The held-out Sportec test match and BAR-ATH were not loaded or scored for P5.
There is therefore no post-failure test-set selection.

## Frozen experiment

- Inputs: common schema `04_full_phase_context`, 72 columns after removing all
  `gtag_*`; 51 sometimes-missing columns receive observation flags, for 123
  model inputs.
- Identity boundary: `frame`, match, competition, provider, team, track, and
  slot identifiers are rejected by preprocessing and covered by tests.
- Split: four whole training matches and two whole validation matches. Scaling
  is fit on training matches only.
- Data: original + two deterministic label-independent damaged copies, and a
  home/away mirror of each training copy. Validation is never augmented.
- Model: one depthwise local temporal convolution and pointwise projection,
  residual into a two-layer pre-norm Transformer; width 64, four heads,
  feed-forward width 128, dropout 0.3, fixed sinusoidal positions.
- Capacity: 79,747 trainable parameters. The recorded P4 architecture has
  approximately 132,739 at the same 123-input boundary.
- Sequence: 10 seconds, every fifth frame, 50 tokens, never crossing a period.
  P4 had already measured 10/30/60-second windows as tied; the shorter setting
  made the deadline run tractable.
- Training: seeds 0/1/2, AdamW 1e-3, gradient clipping 1.0, early stopping on
  grouped validation cross-entropy, then probability averaging and one common
  Viterbi decode.

## Results

All values below use `labels_adjusted`. Tuned penalties come from the common
fixed penalty grid.

| Candidate | Penalty | J03WMX spell/macro | J03WOY spell/macro | Mean spell/macro |
|---|---:|---:|---:|---:|
| P2 GBT rerun | 40 | 0.673 / 0.914 | 0.697 / 0.898 | 0.685 / 0.906 |
| P5 ensemble | 10 | 0.640 / 0.901 | 0.709 / 0.898 | 0.675 / 0.900 |
| 50/50 P2 + P5 | 20 | 0.666 / 0.913 | 0.724 / 0.906 | **0.695 / 0.910** |
| P4 ensemble, recorded in PR 14 | 20 | not committed separately | not committed separately | **0.710 / 0.906** |
| P2 + GRU 30 s + GRU 20 s, recorded in PR 16 | 20 | not committed separately | not committed separately | **0.727 / 0.912** |

P5's unsmoothed mean was 0.302 spellF1 / 0.900 macroF1. The hybrid's
unsmoothed mean was 0.376 / 0.907. P4's recorded unsmoothed mean is 0.440 /
0.904. P5 therefore did not hide a stronger probability model behind a poor
decoder setting.

At the fixed penalty 20, the means were P2 0.666, P5 0.669, and hybrid 0.695
spellF1. The hybrid's tuned penalty is already 20, so its headline is unchanged.

### Common keep rule

The keep test bootstraps spellF1 gain over 97 two-minute chunks.

| Change | Mean chunk gain | 95% interval | Keep? |
|---|---:|---:|---:|
| P2 -> P5 | -0.0203 | [-0.0465, +0.0058] | no |
| P2 -> fixed hybrid | +0.0057 | [-0.0115, +0.0236] | no |
| P5 -> fixed hybrid | +0.0260 | [+0.0055, +0.0479] | yes |

The hybrid is a real improvement over standalone P5 on both validation matches,
but it does not justify replacing the simpler P2 and is still 0.015 below P4's
recorded point estimate.

## Match-bias evidence

The hybrid architecture is not treated as a bias control by itself.

- No match/provider/team/track/slot identity is present in the 72 selected
  columns; preprocessing rejects those names even if supplied later.
- P5 splitting, scaling, early stopping, penalty selection, and reporting is by
  whole match. The two validation matches are always reported separately. P2's
  scikit-learn 1.6 fallback early-stops on an internal training-row fraction;
  its validation scoring and smoothing remain whole-match.
- Standalone P5 regressed P2 on J03WMX and only improved the aggregate score on
  J03WOY. This fails the pre-declared non-negative-per-match direction rule.
- The fixed hybrid improved standalone P5 by nearly identical mean chunk gains
  on both matches (+0.0252 and +0.0268), so that improvement is not isolated to
  one match. Against P2, however, its chunk gain was -0.0123 on J03WMX and
  +0.0240 on J03WOY, so it still fails the cross-match selection rule.
- Hybrid live-frame accuracy was 0.919/0.903 when the ball was visible and
  0.825/0.825 when missing (J03WMX/J03WOY). The expected degradation under
  missing-ball conditions is present; there is no suspicious hidden≈visible
  result.

Leave-one-training-match-out and additional masking retrains were not run after
the primary performance and per-match gates failed. They cannot rescue a model
that is already rejected, and running four more neural fits on the deadline
would spend validation budget without changing the decision. This is reported
as missing robustness evidence, not as a passed check.

## Limitations and blockers

1. P4 PR 14 and blend PR 16 record aggregate validation results but do not
   commit their ignored run probabilities. Exact chunk-bootstrap comparisons
   with P5 cannot be reconstructed without rerunning those branches. This does
   not block rejection because P5 and the hybrid already fail both recorded
   point-estimate thresholds.
2. This Python 3.9 environment resolves scikit-learn 1.6.1 although
   `requirements-team.txt` requests >=1.7. P2 now records and uses the supported
   deterministic internal-training-fraction fallback; grouped explicit
   validation is used when the installed API supports it. This weakens the P2
   hybrid comparison but does not affect standalone P5 or the P4 result.
3. The validation set has only two matches and has already supported earlier
   approach decisions. Confidence intervals and the stop rule are therefore
   more credible than selecting the highest observed point estimate.
4. The three seed runs were executed from a dirty working tree based on commit
   `b67351c`; their metadata predates the new `working_tree_dirty` field. The
   post-run edits to P5 were probability reporting, hybrid evaluation, and
   stricter identity rejection rather than training changes, so exact replay is
   expected but has not been demonstrated from the final commit. Future runs
   record both commit and dirty state.

## Final disposition

- **Completed:** implementation, tests, deterministic damaged copies, three
  seeds, ensemble, fixed hybrid, fixed-penalty report, per-match diagnostics,
  common keep tests, and decision record.
- **Rejected:** standalone P5 and the P2/P5 hybrid as replacements for P4 or
  the current three-way blend.
- **Retained best recorded candidate:** the P2 + GRU 30 s + GRU 20 s blend at
  0.727 validation / 0.718 one-shot test, pending review and merge of PR 16.
- **Retained best recorded single model:** P4, pending review and merge of PR 14.
- **Not performed:** Sportec test and BAR-ATH scoring, because P5 failed
  validation and was frozen as a negative result.
