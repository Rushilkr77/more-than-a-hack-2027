# P2: gradient-boosted trees

P2 keeps its existing GBT process: it trains on raw Sportec labels every fifth
frame, includes a home/away-mirrored copy, early-stops on validation matches,
and tunes the shared Viterbi smoothing penalty on adjusted validation labels.

Its model features now come exclusively from the common contract:

```python
match = sportec.load(match_name)
inputs = sportec.classification_inputs(match, train_p2.P2_POLICY)
```

`P2_POLICY` selects `04_full_phase_context` in offline/acausal mode. The final
P2 variant then removes `gtag_*`, as before, and adds its past/next 1, 5, and
15-second mean, standard-deviation, and difference features within each half.
It never reads the unrestricted frame table for model features.

Run it with:

```bash
python scripts/train_p2.py              # one model, seed 0
python scripts/train_p2.py --ensemble   # final-submission form: P(H), P(A), P(D) averaged over seeds 0, 1, 2
```

`--ensemble` averages the three seeds' probabilities, then applies the common smoother (penalty tuned on validation).
Outputs go to `outputs/p2/<variant>_ens`.

P2 training requires Python 3.10+ and `scikit-learn>=1.7`: that version adds
the explicit validation-set API used for its existing early-stopping process.

## Results (final P2 = `h_sd_win_1_5_15`, no `gtag_*`, 282 features)

spellF1 / macroF1. "Single" is the mean of three separate seed runs; "Ensemble" is the seed-averaged model. The smoother
penalty is 20 in every row and was tuned on Sportec validation only.

| | Sportec validation | Sportec test (J03WQQ) | BAR-ATH public 5 min |
|---|---|---|---|
| Ensemble, smoothed | 0.668 / 0.899 | 0.662 / 0.904 | 0.735 / 0.817 |
| Ensemble, unsmoothed | 0.363 / 0.900 | 0.345 / 0.899 | 0.380 / 0.844 |
| Single, smoothed | 0.671 / - | 0.653 / 0.901 | 0.734 / 0.838* |
| Single, unsmoothed | 0.313 / - | 0.300 / 0.897 | 0.288 / 0.835 |
| Baseline smooth50 | 0.219 / - | 0.223 / 0.461 | 0.326 / 0.621 |
| Baseline raw | 0.049 / - | 0.042 / 0.428 | 0.039 / 0.597 |

\*seed 0 only.

- The ensemble matches the single-seed mean once smoothed and is clearly better unsmoothed (about +0.05 spellF1, +0.09
  on BAR-ATH). Use it for the final submission; use the single-seed mean when comparing approaches during development.
- BAR-ATH has 17 possessions: the smoothed spellF1 interval is about 0.53-0.90, so gaps under about 0.1 are not significant.
- The Sportec test match was scored for these numbers (single seeds once, ensemble once). Make no further decisions on it.
- `gtag_*` was tested as a whole block and in 11 sub-forms; none adds a gain that holds on BAR-ATH
  (`gtag_poss` costs about 0.09 there), so it stays out. See `docs/models/P2_LEARNINGS_FOR_P4.md`.
