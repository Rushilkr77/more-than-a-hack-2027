# P2: gradient-boosted trees

P2 keeps its existing GBT process: it trains on raw Sportec labels every fifth
frame, includes a home/away-mirrored copy, early-stops on validation matches,
and tunes the shared Viterbi smoothing penalty on adjusted validation labels.

Its model features now come exclusively from the common contract:

```python
match = sportec.load(match_name)
inputs = sportec.classification_inputs(match, train_p2.P2_POLICY)
```

`P2_POLICY` selects `04_full_phase_context` in offline/acausal mode. The final
P2 variant then removes `gtag_*`, as before, and adds its past/next 1, 5, and
15-second mean, standard-deviation, and difference features within each half.
It never reads the unrestricted frame table for model features.

Run it with:

```bash
python scripts/train_p2.py
```

P2 training requires Python 3.10+ and `scikit-learn>=1.7`: that version adds
the explicit validation-set API used for its existing early-stopping process.
