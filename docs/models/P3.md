# P3: offline TCN possession prediction

P3 trains two separate temporal-convolution models for frame-level `H`, `A`,
or `D` possession prediction. It uses the maintained `pytorch-tcn` backbone;
P3 code owns only data preparation, training, artifact storage, and decoding.

## Fixed input contract

P3 uses the supplied schemas exactly as defined in
`src/features/model_inputs.py`:

| Run | Schema | Channels |
|---|---|---:|
| 03 | `03_ball_shape_extended` | 60 |
| 04 | `04_full_phase_context` | 80 |

No columns are added, removed, engineered, or concatenated. Schema 04 retains
all `gtag_*` columns. Numeric values are standardised from train-match
statistics only; a missing value becomes zero **after** standardisation, and
no missingness-mask channel is created.

## Offline temporal alignment

P3 predicts target frame `t` from a 101-frame same-period window:

```text
t-75 ... t-1 | t | t+1 ... t+25
  3 seconds    target    1 second
```

The packaged TCN is causal. Its final output is aligned back to `t`, which is
valid because this is offline possession prediction. The 101-frame receptive
field comes from five blocks, kernel size 3, and dilations `1, 2, 4, 8, 10`.
The window builder repeats only the nearest same-period edge frame; it never
uses a frame from the other half.

All parameters are versioned in [`configs/p3_tcn.json`](../../configs/p3_tcn.json),
not embedded in training code.

## Data and selection contract

- Train on raw Sportec labels from the fixed four-match train split, including
  the shared Home/Away mirror augmentation.
- Use the two validation matches for early stopping and Viterbi penalty tuning.
- Pick one schema by smoothed validation spellF1, with macroF1 only as a tie-break.
- Run held-out `J03WQQ` only after selection. BAR-ATH is inference-only.

`scripts/validate_model_inputs.py` passed all seven Sportec matches. Both P3
schemas have no all-missing or constant columns and the data layer reports
`ready_for_model_training`. PyTorch 2.15.0 and `pytorch-tcn` 1.2.3 are
installed in this worktree's `.venv`.
